# Fruit Ripeness Grading using CNN

CNN-based image classifier (MobileNetV2) that grades fruit ripeness
as unripe / ripe / overripe from surface images. Delivered as a
Streamlit produce-sorting line assistant.

## Keywords
fruit, ripeness, grading, cnn, image, classifier

## Dataset
Fruit images from orchard and market photographs (Kaggle dataset + own photos).
Link: <Kaggle dataset link ikkada pettandi>

## Setup
pip install -r requirements.txt

## Train
python train.py --data data/banana

## Run the app
